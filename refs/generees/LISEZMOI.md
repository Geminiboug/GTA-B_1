# Images générées (références de style)

Images fournies par Olympe le 19/10/2026, générées par IA (Google Gemini). Elles servent de références de style et de
matière pour les textures et les modèles. Ce ne sont **pas des photos** : l'IA invente de façon plausible.

Règles :
- les couleurs, proportions et détails « réels » (ligne au milieu de la route, gilets des zems, formes des toits) se
  valident avec les photos de terrain (docs/photos_terrain.md) ; en cas de désaccord, la photo gagne ;
- aucun texte visible sur ces images (noms de boutiques, de quartiers, numéros de téléphone) ne passe tel quel dans le
  jeu : on ne garde que le style (docs/LEGAL.md) ;
- textures tirées de ces planches : découpées, rendues raccordables, rangées dans godot/assets/textures/ avec leur
  planche d'origine notée dans le script qui les produit.
