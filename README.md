# GTB (Gbê Town Bénin)

Jeu open world 3D ancre au Benin. Premiere zone : aeroport de Cotonou, Erevan, la plage.

## Stack
- Blender 4.x, export glTF 2.0 (.glb)
- Godot 4.x
- Echelle : 1 unite = 1 metre

## Structure
- `blender/` : fichiers sources .blend
- `godot/` : projet Godot
- `docs/` : roadmap et documentation
- `refs/` : photos de reference (rues, facades, carrefours, sols, enseignes, vehicules, props)

## Nommage
`bld_` batiments, `prop_` objets, `veh_` vehicules, `chr_` personnages
